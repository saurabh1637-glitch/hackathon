# TransitOps — Smart Transport Operations

Frontend-only demo for fleet management. Data is stored in your browser's localStorage. No backend, no login.

## Requirements
- Node.js 18 or newer (check with `node -v`)
- VS Code

## Run it
Open the `transitops` folder in VS Code, then open the terminal (Terminal > New Terminal) and run:

```bash
npm install
npm run dev
```

Open the link shown in the terminal (usually http://localhost:5173).

## Build for production
```bash
npm run build
npm run preview
```

## Reset demo data
Go to Settings > Reset demo data.
